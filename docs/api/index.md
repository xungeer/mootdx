# Python API

Mootdx 的 Python 接口分为在线行情、本地数据和专业财务数据三组。在线行情又分为标准市场与扩展市场；两者连接不同的通达信服务，不能混用证券代码和市场编号。

首次使用前请先阅读 [公共约定](conventions.md)。其中统一说明了工厂方法、市场常量、K 线周期、DataFrame 返回规则、连接生命周期和内部协议边界。

## 在线行情

- [标准行情](quote1.md)：深市、沪市、北交所证券的行情、K 线、服务端复权、证券列表、财务摘要、公司资料和板块信息。
- [扩展行情](quote2.md)：期货、期权、港股及服务器提供的其他扩展市场。可用市场必须以 `markets()` 的实时结果为准。

## 本地与财务数据

- [离线数据](reader.md)：读取通达信安装目录中的日线、分钟线、板块和自定义板块文件。
- [专业财务数据](affair.md)：查询、下载和解析通达信专业财务文件。
- [财务字段](fields.md)：专业财务文件的字段说明。

## 辅助能力

- [辅助工具](extras.md)：复权数据采集、导出文件转换、节假日和自定义板块工具。

命令行接口与 Python API 的参数并不完全相同，请在“命令行工具”章节查看对应说明。
